**Ecommerce sale Dashboard.******
This project is an interactive Excel dashboard designed to analyze ecommerce sales performance using KPIs, charts, maps, and filters. It provides a complete overview of sales, profit, quantity sold, customer segments, categories, and regional performance.
______________________________________________________________
📌 Key Performance Indicators (KPIs)
Total Sales
Total Profit
Quantity Sold
Number of Orders
Profit Margin
Year-over-Year (YoY) Growth for each KPI

📊Visualizations
Sales & Profit Trend Chart
Category-wise Profit Waterfall Chart
Category-wise Sales Share Pie Chart
Sales by U.S. States Map
Top 5 Subcategories by Sales
Interactive Slicers/Filters:
Year
Segment
Region


🧰Tools Used
Microsoft Excel
Power Query
Pivot Tables
Pivot Charts
Slicers
Conditional Formatting


🎯 Purpose of the Dashboard
This dashboard helps in:
Monitoring ecommerce business growth
Identifying profitable categories
Analyzing regional performance
Understanding sales trends
Supporting business decision-making
